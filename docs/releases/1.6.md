**Download:**
- `Zeus-Poseidon-macos-arm64.zip`: Apple Silicon Mac, macOS 14 or later.
- `Zeus-Poseidon-macos-intel.zip`: Mac with an Intel processor, macOS 15 or later.
- `Zeus-Poseidon-linux-x86_64.AppImage` and `Zeus-Poseidon-linux-aarch64.AppImage`: Linux (Ubuntu 22.04, Debian 12, Fedora 36 or later).

You need your own copy of the game: the GOG installer of *Zeus + Poseidon*, or the game installed with Steam.

## What is new

- **The Mac applications unpack the GOG installer by themselves again.** The archives of 1.2 to 1.5 were built without innoextract, so on a Mac without Homebrew the application stopped at "innoextract is not installed" when given the GOG installer. innoextract and its libraries are now inside the application, and the release chain refuses an archive without them ([#134](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/134)). If you installed it with `brew install innoextract` as a workaround, you can keep it or remove it.
- **A game placed inside the application starts without a question**, for one's own use with one's own game (`tools/make_app.py --game FOLDER`). The published archives contain no game file.

**Thank you to [@MohammadBnei](https://github.com/MohammadBnei)**, who tried the application on a clean Mac, found the cause and proposed the fix. Reports like this one make the project better for everyone.

Nothing else changes: the game runs as in 1.5, frames and game state identical to the original in the ten scenarios.

## First launch

- **Mac:** unzip, double-click **Zeus Poseidon.app**. The application is not notarized by Apple: open *System Settings → Privacy & Security*, click **Open Anyway**, then pick your GOG installer or game folder.
- **Linux:** make the AppImage executable (`chmod +x`), run it.

Every archive and AppImage is built and self-tested by the CI; none contains a game file. Please report anything odd in an [issue](https://github.com/nic0lasm/zeus-poseidon-arm64/issues).
