**Download:**
- `Zeus-Poseidon-macos-arm64.zip`: Apple Silicon Mac, macOS 11 (Big Sur) or later.
- `Zeus-Poseidon-macos-intel.zip`: Mac with an Intel processor, macOS 11 (Big Sur) or later.
- `Zeus-Poseidon-linux-x86_64.AppImage` and `Zeus-Poseidon-linux-aarch64.AppImage`: Linux (Ubuntu 22.04, Debian 12, Fedora 36 or later).

You need your own copy of the game: the GOG installer of *Zeus + Poseidon*, or the game installed with Steam.

## What is new

- **Older Macs: macOS 11 and later.** Until 1.6 the Mac archives needed macOS 14 on Apple Silicon and macOS 15 on Intel, because the libraries they bundle came from Homebrew and were built for the newest system. SDL, Unicorn and innoextract are now built from their sources for macOS 11, and so is the program. Every Apple Silicon Mac can run it, and Intel Macs from 2013 onwards that stopped at macOS 11 or 12 ([#139](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/139)).

**Please tell us if you try it on macOS 11, 12 or 13.** The CI checks that every binary in both archives asks for macOS 11.0 at most and runs the self-test, but GitHub has no Mac older than macOS 14, so these versions have not yet been tried on a real machine. A word on [#139](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/139), working or not, helps every player with an older Mac.

Nothing else changes: the game code is the same as in 1.6, frames and game state identical to the original in the ten scenarios. The Linux AppImages are unchanged.

## First launch

- **Mac:** unzip, double-click **Zeus Poseidon.app**. The application is not notarized by Apple: open *System Settings → Privacy & Security* (on macOS 11 and 12: *System Preferences → Security & Privacy → General*), click **Open Anyway**, then pick your GOG installer or game folder.
- **Linux:** make the AppImage executable (`chmod +x`), run it.

Every archive and AppImage is built and self-tested by the CI; none contains a game file. Please report anything odd in an [issue](https://github.com/nic0lasm/zeus-poseidon-arm64/issues).
