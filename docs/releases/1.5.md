**Download:**
- `Zeus-Poseidon-macos-arm64.zip`: Apple Silicon Mac, macOS 14 or later.
- `Zeus-Poseidon-macos-intel.zip`: Mac with an Intel processor, macOS 15 or later.
- `Zeus-Poseidon-linux-x86_64.AppImage` and `Zeus-Poseidon-linux-aarch64.AppImage`: Linux (Ubuntu 22.04, Debian 12, Fedora 36 or later).

You need your own copy of the game: the GOG installer of *Zeus + Poseidon*, or the game installed with Steam.

## What is new: the Steam edition

- **Found by itself.** If *Zeus + Poseidon* is installed with Steam, the application finds it at first launch: Steam's main library and the other libraries listed in `libraryfolders.vdf`, on Linux, in Flatpak and on a Mac. A Steam folder can also be picked with *Folder…* ([#135](https://github.com/nic0lasm/zeus-poseidon-arm64/pull/135), [#128](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/128)).
- **`Zeus.exe` checked at launch.** The application compares the game's executable with the GOG build it was proven against (SHA-256). Another build still runs, after a warning shown once, which asks for a report on [#128](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/128): the Steam build is very likely the same file, and one report from a Steam player settles it.
- **The README explains the Mac case**: Steam for Mac does not offer this Windows game, so on a Mac you copy the `Zeus + Poseidon` folder from a Windows PC (`Steam\steamapps\common`) and choose it with *Folder…*.

Nothing else changes: the game runs as in 1.4, frames and game state identical to the original in the ten scenarios.

## First launch

- **Mac:** unzip, double-click **Zeus Poseidon.app**. The application is not notarized by Apple: open *System Settings → Privacy & Security*, click **Open Anyway**, then pick your GOG installer or game folder.
- **Linux:** make the AppImage executable (`chmod +x`), run it.

Every archive and AppImage is built and self-tested by the CI; none contains a game file. Please report anything odd in an [issue](https://github.com/nic0lasm/zeus-poseidon-arm64/issues).
