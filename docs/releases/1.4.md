## What is new: a lighter display

- **Frames copied in place.** The game's DirectDraw copies now work directly in the emulated memory instead of line by line through the emulator, and the screen is handed to the window without being read back whole ([#131](https://github.com/nic0lasm/zeus-poseidon-arm64/pull/131), fixes [#125](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/125)).
- **The window's texture in the renderer's own format**, filled in one pass through a colour table: converting a 1024×768 frame takes **0.65 ms instead of 4.1 ms**. The window is identical pixel for pixel.
- **7 to 12 % less CPU** for the whole application on a large city, with the window visible (150 s in real time).
- **Loading a game was measured**: 0.16 s for the large city, so nothing there needed speeding up ([#126](https://github.com/nic0lasm/zeus-poseidon-arm64/issues/126)).

| Measure | 1.2 | 1.3 | 1.4 |

## How it is proven

- **Ten replayable scenarios**: every frame and the whole game state, at every simulation tick, compared with the pure original ([equivalence.md](https://github.com/nic0lasm/zeus-poseidon-arm64/blob/main/docs/equivalence.md)).

The full list is in [CHANGELOG.md](https://github.com/nic0lasm/zeus-poseidon-arm64/blob/main/CHANGELOG.md).

## First launch

- **Mac:** unzip, double-click **Zeus Poseidon.app**. The application is not notarized by Apple: open *System Settings → Privacy & Security*, click **Open Anyway**, then pick your GOG installer.
- **Linux:** make the AppImage executable (`chmod +x`), run it and pick your GOG installer.

Every archive and AppImage is built and self-tested by the CI; none contains a game file. Please report anything odd in an [issue](https://github.com/nic0lasm/zeus-poseidon-arm64/issues).
